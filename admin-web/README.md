# HoYoCalendar 管理后台（Web）

简洁的管理员控制台：登录、邀请码、用户禁用、会话撤销、脱敏 AI 用量、全局预算/总开关与审计列表。

## 运行

管理 API 只监听服务器 `127.0.0.1:8001`，本控制台也只绑定 `127.0.0.1`，**必须通过 SSH 隧道访问**。

在服务器上（`cloud/` 同级）：

```bash
python3 admin-web/server.py --port 8080 --api-port 8001
```

然后在本地电脑建立隧道（把 `user@server` 换成实际地址，`8080` 默认转发到服务器本机）：

```bash
ssh -L 8080:127.0.0.1:8080 user@server
```

打开浏览器访问 `http://127.0.0.1:8080`，使用服务器 `.env` 中的管理员用户名与密码登录
（`ADMIN_USERNAME` / 密码哈希 `ADMIN_PASSWORD_HASH` 对应的原始密码）。

## 说明

- `server.py` 仅依赖 Python 标准库，负责托管静态文件并把 `/api/*` 代理到
  `http://127.0.0.1:8001/api/*`，浏览器与 API 同源，不需要 CORS。
- 令牌仅保存在当前浏览器会话（sessionStorage），关闭浏览器即失效；退出登录会同时撤销服务端会话。
- 接口严格对齐冻结契约 `cloud/openapi/admin.openapi.json`，未新增或修改任何后端字段。
- 页面不展示模型密钥、提示词、日历正文等敏感内容，AI 用量为脱敏汇总。
- 生产环境应将该控制台置于反向代理（同样仅限本机）或继续使用 SSH 隧道，不要暴露到公网。
